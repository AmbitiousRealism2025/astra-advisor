# Security reporting

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/AmbitiousRealism2025/astra-advisor/security/advisories/new).

Do not post credentials, private source, raw session files, or sensitive exploit details in a public issue. Use synthetic data where possible. Include the affected commit, Pi version, operating system, reproduction steps, and expected versus actual behavior.

This project is experimental. There is no established support window or guaranteed response time. Review the [security boundary and resource limits](docs/security-and-limits.md) before use. The read-only reviewer is not an operating-system sandbox, and a passing review is not a security certification.
